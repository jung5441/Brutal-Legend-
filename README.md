# Brutal Legend 한국어 패치

Double Fine Productions의 **Brutal Legend**를 한국어로 플레이하기 위한 비공식 한글패치입니다.

현재 **PC / PlayStation 3 / Xbox 360** 버전을 지원합니다.

> [!IMPORTANT]
> **PS3판과 Xbox 360판은 실제 콘솔 본체에서 실기 테스트를 진행하지 않았습니다.**
> 에뮬레이터 환경과 정적 검증을 기준으로 제작되었습니다.
> 실제 PS3 / Xbox 360 본체에서는 예상하지 못한 문제가 발생할 수 있습니다.

# PC

## 파일

BrutalLegend_KoreanPatch_Distribution_V1.1.exe

## 사용 방법

1. 패치툴을 실행합니다.
2. Brutal Legend가 설치된 게임 폴더를 지정합니다.
3. **한글패치 적용 / 업데이트**를 실행합니다.
4. 패치툴이 순정 파일을 확인하고 자동으로 백업한 뒤 한글패치를 생성합니다.
5. 문제가 있을 경우 **순정 복원** 기능으로 원본 상태로 복구할 수 있습니다.

- 최신 번역 데이터 및 폰트 포함

# PlayStation 3

## 지원 버전

- Region: USA
- Title ID: **BLUS30330**
- Game Version: **1.02**

## 파일

BrutalLegend_PS3_KR_Patch_V1.0.exe

## 사용 방법

1. PS3 게임을 **폴더 형태로 추출**합니다.
2. 패치툴을 실행합니다.
3. 다음 중 하나를 지정합니다.
   - PS3_GAME이 들어 있는 게임 루트
   - PS3_GAME 폴더
   - PS3_GAME\USRDIR\Packs\PS3 폴더
4. **한글패치 적용 / 업데이트**를 실행합니다.
5. 패치툴이 지원되는 순정 파일의 SHA-256을 확인하고 자동으로 원본을 백업합니다.
6. 텍스트 / 폰트 / 영상 자막 / 이미지를 직접 생성하여 적용합니다.

## 적용 내용

- 한국어 텍스트 16,164행
- PS3 버튼 표기 보정
- 폰트 포함 GFX 63개
- DefineFont3 85개
- PREF 영상 enUS 한국어 자막 활성화
- 한글화 이미지 22개
  - 도로 표지판 13개
  - 로딩 이미지 9개

## PS3 테스트 상태

> [!WARNING]
> **실제 PS3 본체에서는 테스트하지 않았습니다.**
>
> 패치 생성, 재추출, 해시 비교 등의 정적 검증과 에뮬레이터 환경에서의 동작 확인을 기준으로 제작했습니다.
> 실제 PS3 본체에서의 정상 동작을 보장하지 않습니다.

### 참고

- ISO 파일 자체를 직접 선택하는 방식은 지원하지 않습니다.
- ISO를 먼저 폴더 형태로 추출해야 합니다.
- 지원 순정 버전이 아닌 파일에는 적용되지 않습니다.
- xdelta 방식이 아닙니다.
- 최초 적용 시 순정 팩을 별도 백업합니다.
- **순정 복원** 기능을 지원합니다.

# Xbox 360

- 본편: Brutal Legend (USA, Europe) (En,Fr,De,It)
- DLC: 454108C5\00000002
- TU: TU_12K2265_000000G000000.0000000000084

## 파일

BrutalLegend_Xbox360_KoreanPatch_V1.0.exe

## 사용 방법

2. 본편 게임 폴더 또는 Packs\360 폴더를 지정합니다.

6. 순정 본편 / DLC / TU를 확인하고 자동으로 백업한 뒤 패치를 직접 생성합니다.
7. 필요할 경우 **순정 복원** 기능으로 원상복구할 수 있습니다.

- 본 패치는 **비공식 팬 제작 한글패치**입니다.
- 원본 게임 데이터 자체를 배포하기 위한 프로젝트가 아닙니다.

- 지원 버전과 다른 게임 파일에 강제로 적용하지 마세요.
